# 🎰 CASINO ROYALE – TRAGAMONEDAS EN PYTHON

## 📌 Descripción del proyecto

Casino Royale es un simulador de máquinas tragamonedas desarrollado en Python como proyecto de Programación Orientada a Objetos (POO).

El programa permite interactuar con diferentes máquinas tragamonedas mediante un menú en la terminal, realizar apuestas, obtener premios y consultar estadísticas de juego.

## 🎯 Objetivo

Aplicar los conocimientos de Programación Orientada a Objetos mediante el desarrollo de un sistema interactivo que simula el funcionamiento de un casino.

## 🕹️ Funcionalidades principales

- Menú interactivo para seleccionar máquinas tragamonedas.
- Tres máquinas con diferentes nombres y créditos iniciales.
- Sistema de apuestas utilizando créditos virtuales.
- Generación aleatoria de símbolos.
- Evaluación de combinaciones ganadoras.
- Actualización del saldo según los resultados.
- Registro de jugadas, apuestas y premios.
- Visualización de estadísticas.
- Resumen general al finalizar el programa.
- Validación de opciones ingresadas por el usuario.

## 🧠 Conceptos de POO utilizados

**Clases y objetos:** permiten representar las máquinas tragamonedas como entidades independientes.

**Constructores:** inicializan los atributos de cada máquina.

**Encapsulamiento:** permite organizar y controlar el acceso a los datos de los objetos.

**Métodos:** implementan acciones como jugar, mostrar información y consultar estadísticas.

**Atributos:** almacenan información como el nombre de la máquina, créditos, apuestas y premios.

## ▶️ Cómo ejecutar el programa

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Verificar que Python esté instalado.
4. Abrir una terminal en la carpeta que contiene `main.py`.
5. Ejecutar el comando:

```bash
python main.py
```

6. Seleccionar una máquina y seguir las instrucciones del menú.
